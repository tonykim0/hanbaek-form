## 관측된 규칙
- **트리거 패턴이 운영사 정체성**:
  - 플러그링크 = 환경부승인 → 준공마감
  - 나이스·SK = 착공 → 준공마감
  - 현대엔지니어링 = 환경부승인 → 착공 → 준공마감 (유일한 3단계)
  - 에버온 = 환경부승인 → 준공마감
  - 자체투자·시공만 = 준공마감 1회 (일시금)
- **1차 유형은 항상 정액**. 2차가 잔액인 경우가 많음(플러그링크·나이스·SK 환경부). 현대·에버온은 2차도 정액.
- **잔액 계산엔 턴키단가 필요**: 턴키(대당) = 영업비 + 시공비 + 한백마진.
- 부가 필드: `감리비용 부담`(예: 영업비 차감), `전기안전점검수수료 부담`(예: 한백 부담),
  `비고`(프로모션: "6개월 149원+6개월 249원" 등).
- 매트릭스에 상/하반기 구분 있음(`적용 시작일`). 같은 조건도 반기별 단가 다름.

## 케이스 선택 축 (접수 단가 지정 시 필터)
운영사 + 사업구분 + 수전방식 + 계약기간 + 신설·교체 구분 + 적용시작일(상/하반기)
→ 이 조합으로 매트릭스에서 케이스 1건 매칭. 건축물유형(공동/상업)도 일부 케이스 구분에 쓰임.
